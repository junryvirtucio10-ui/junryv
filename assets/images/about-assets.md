# About portrait

`grethiel-about.webp` uses the original supplied `grethiel-joy.png` photo. The original RGB pixels are retained; only a transparency mask is taken from the background-removal output. Transparent margins are trimmed, and the result is saved as lossless WebP.

The built-in imagegen tool was used for background extraction with this prompt:

> Remove only the gray studio background, preserving the full original canvas, aspect ratio, subject position, face, smile, angled pose, curly hair, beige blazer, white top, and torso crop. Do not redraw, retouch, relight, scale, or reposition the woman. Preserve fine hair edges without a halo. The result is used only as an alpha mask applied to the untouched original photo.
